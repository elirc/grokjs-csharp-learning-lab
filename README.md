# C# Basics

This is a beginner-to-intermediate collection of focused C# example files, following the same educational style as the JavaScript Learning Lab.

Each file teaches **one core concept** using plain C# (no external packages unless noted for realism).

## Goals
- Help noob coders learn C# fundamentals through small, realistic examples
- Heavy inline comments explaining specific lines
- Structured sections: BEGINNER GOAL, REAL WORLD USE CASE, CONCEPTS, code, LINE-BY-LINE BREAKDOWN, NOOB TRANSLATION, COMMON MISTAKES, TRY CHANGING THIS, MINI CHALLENGE

## How to Study
1. Open one file at a time.
2. Read the top comment block.
3. Read code + comments.
4. Use the bottom sections for deeper understanding.
5. Experiment in a console app or .NET Fiddle / VS Code.

## Recommended Order
Follow the numbered files sequentially.

Files cover:
- Variables, types, strings, numbers, bools
- Conditionals, loops
- Arrays, Lists, Dictionaries
- Methods, parameters, return values
- Classes, objects, properties
- Inheritance, interfaces, polymorphism
- Exception handling
- Basic async/await
- And more...

All files use .cs extension. To run, create a simple console project and copy/paste the relevant code.

## Notes
- Focus is on the C# language itself.
- .NET framework/ecosystem concepts are in the sibling `dotnet-learning-lab` folder.
- Use Visual Studio, VS Code + C# Dev Kit, or online tools like .NET Fiddle for experiments.

Good luck! This will give you a solid foundation in C#.
